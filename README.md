Crypta-Obscura
Crypta-Obscura is a fork of Shattered Pixel Dungeon, reimagined as a narrative-driven roguelike RPG.
It retains the roguelike foundation — procedural dungeon generation, turn-based combat, and class progression — while introducing:

Painterly fantasy visuals

Gothic and cosmic themes woven into environments and lore

Expanded narrative systems with quests, dialogue, and character arcs

Custom UI and assets for a darker, atmospheric tone
